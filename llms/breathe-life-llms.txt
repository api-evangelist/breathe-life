# Breathe Life

> Breathe Life was a Montreal, Quebec life insurance technology company (founded 2018) that sold carriers the Breathe Life Hybrid Origination Platform — Quoter, Hybrid e-App, Advisor Tools and Data Dashboards — as licensed enterprise SaaS. It was acquired by SE2 (an Eldridge business, now Zinnia) on 2022-03-28, and breathelife.com has since been decommissioned. **Breathe Life never published a public API, developer portal, OpenAPI/Swagger definition, GraphQL endpoint, webhook catalog or Postman collection.** This record exists as an accurate negative in the API Evangelist catalog.

## Status

- Corporate status: acquired 2022-03-28 by SE2, an Eldridge business; SE2 later rebranded as Zinnia
- Web presence: decommissioned. breathelife.com returns an nginx "Site Not Configured" 404; www.breathelife.com returns a WP Engine "Site is not available" 404
- API surface: none, past or present
- Product successor: Zinnia "Hybrid Origination" — a different legal entity, not this record

## APIs

None. Breathe Life published no public API. Quote, bind and issue existed as real product capability (the Quoter and Hybrid e-App modules) but only inside a carrier-licensed, login-gated SaaS application. FNOL was never in scope — the platform covered new-business origination and distribution, not claims.
